Going further — coding agents, more power, more risk

Using AI-friendly websites from Claude Code and OpenAI Codex — agents that can fetch, save, and act on what they read.

The basic tier gives your AI eyes. This tier gives it hands.

Claude Code (Anthropic) and Codex (OpenAI) are coding agents: AI sessions that run with access to a real computer — usually yours. They can fetch this site the same way the chat apps do, but they can also keep what they read: save the Markdown mirrors to disk, diff a page against the version they saved last week, pull llms-full.txt (every page in one file) into a project, or wire a site's content into something they're building for you.

What the power buys you

  • Persistence. "Save the mirrors of this site into my notes folder and keep them updated" — a chat app can't; a coding agent can.
  • Composition. "Read this site's guide and apply it to my project" — the agent reads the friendly version and then edits your files accordingly.
  • Automation. "Every morning, fetch the llms.txt of these three sites and tell me what changed."

AI-friendly sites are what make this reliable. An agent automating against scraped HTML breaks when the design changes; one reading published Markdown mirrors is reading a stable contract.

What the power costs — read this part

A coding agent runs with real permissions on a real machine. The risks are not hypothetical:

  • It can change things. Files, configuration, anything its permissions reach. A misunderstood instruction executes instead of just reading wrong.
  • Web content becomes input to a system that acts. A malicious page can try to smuggle instructions to your agent ("prompt injection"). Good agents treat page content as data, not commands — but the attack class is real, and it is the reason this tier is not the default.
  • Credentials amplify everything. An agent that can push to your repos or call your cloud accounts turns a small mistake into a big one.

House rules if you adopt this tier: run agents in a directory you can afford to lose, review what they did before you trust it, give them the fewest permissions that work, and never paste secrets into a session.

Try it

From a Claude Code or Codex session:

Fetch https://denson.github.io/aifriendlywebsites/llms.txt, then fetch the Markdown mirror of each page it lists, and save them under ./aifw-mirrors/. Tell me what the appendix of each mirror says that the pages don't.

That exercise demonstrates the whole architecture in one pass: the index, the mirrors, the agent-only appendices — and the fact that your agent just did something a chat app cannot.

# What is an AI-friendly website?

Most websites are written for human eyes. When an AI reads one, it scrapes
the page and guesses at the structure — and loses whatever the design buried.

An **AI-friendly website** is built the other way around. Every page starts
as Markdown — the format AI tools read natively — and the web page you see is
generated *from* it. The human page is the subset; the AI's version is the
canon.

This site is built that way, which makes it the demo: the page you are
reading right now has a machine-readable twin your AI is reading at the same
time.

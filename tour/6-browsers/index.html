The shared view

Tour 6 of 9 — where you and your AI look at the same page.

Where each app puts the page, as of August 9, 2026:

  • Claude Cowork — no in-app browser this week; it drives your own Chrome via the Claude in Chrome extension instead. Open a fresh Chrome window first — the tour tab lands in it, easy to spot. (Its OpenAI equivalent already has a pane, so expect this to change.)
  • ChatGPT Work & OpenAI Codex — share the same in-app browser (the right-hand pane) and can also drive your external browser, with the same buried-tab catch. Can't see the page? Say so — your AI can move it into the pane.
  • Claude Code desktop — a true in-app pane (Ctrl+Shift+B / Cmd+Shift+B), sandboxed, approvals on consequential actions.
  • Plain chat apps — no visible browsing; your AI reads pages invisibly. Fine for everything this site teaches.

The best seat is always the in-app browser — ask for it first. Today's trade: Cowork offers the most guardrails; Claude Code desktop and OpenAI Codex the most capabilities — the trade the next two pages cover. This page is dated because these details move weekly.

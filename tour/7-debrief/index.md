# What just happened

Three things, quietly, during this tour:

1. **Your AI read the canon while you read the pages.** Every page you saw,
   it saw as Markdown — including appendices written only for it. Ask it
   what the appendices added.
2. **You practiced the habit.** Paste a URL, ask your question, get an
   answer grounded in what the site actually says. That works on any
   website, today.
3. **You saw the trade.** Chat apps: eyes, low risk. Coding agents: hands —
   persistence, composition, automation — and real risk to manage.

**Where this goes:** try the habit on a site you actually use this week. If
it pays off, the coding-agent tier is waiting when you are — with the house
rules from the last page.

This tour stays open — ask your AI anything you're still wondering about.
